# Contributing

Active development has moved to
[`metadata-research/matsci-sam`](https://github.com/metadata-research/matsci-sam).
This legacy repository is retained for historical reference and is not
connected to the current Superego development or Ego public release process.

Do not open new feature branches or pull requests here. For current
instructions, including local setup, required checks, and the Superego testing
handoff, read the
[MatSci-SAM contribution guide](https://github.com/metadata-research/matsci-sam/blob/dev/contributing.md).
Code and documentation changes target the protected `dev` branch in the
MatSci-SAM repository.
